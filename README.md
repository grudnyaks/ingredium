# Ингредиум

Приложение по косметической химии для косметологов и потребителей: гид INCI, регуляторика шести юрисдикций, обучение с геймификацией и сканер составов. **Только проверенные источники:** если данных нет, приложение пишет «не проверено».

**Открыть:** https://grudnyaks.github.io/ingredium/ (после включения GitHub Pages, см. ниже)

Концепция: [docs/CONCEPT.md](docs/CONCEPT.md)

## Возможности v0.1
- 33 114 INCI из CosIng и 2 374 позиции Приложений II–VI Регламента (ЕС) 1223/2009.
- 11 глубоких карточек с источниками у каждого факта.
- Режимы «Потребитель» и «Косметолог», переключатель RU / EU / US / KR / CN / JP.
- Курс, бесконечная викторина из официальных данных, интервальное повторение, XP, уровни, серии с заморозкой.
- Сканер: фото → OCR на устройстве → разбор, флаги ЕС, аллергены отдушек, гипотеза типа средства.
- Темы: системная, светлая, тёмная, 4 пресета, своя.
- PWA: установка на iPhone, офлайн, обновления по воздуху.

## Установка на iPhone
Safari → открыть ссылку → «Поделиться» → «На экран Домой».

## Обновление по воздуху
1. Изменить код или данные.
2. Поднять версию в `app/js/app.js` (`APP_VERSION`), `app/sw.js` (`VERSION`) и `app/version.json`. Если менялись данные, поднять ещё `DATA_VERSION` в `app/js/data.js` и `DATA` в `app/sw.js`.
3. Выполнить `tools/deploy.sh`. Пользователи увидят «Доступно обновление».

## Разработка
```bash
python3 tools/build_cosing.py      # пересобрать данные из data-src/
python3 -m http.server -d app 8000 # локальный запуск
python3 tests/e2e.py               # 89 проверок в эмуляции iPhone (Playwright + Chrome)
```
