# Ингредиум: концепция приложения

Справочник, тренажёр и сканер составов по косметической химии для косметологов и внимательных потребителей.

## 1. Главный принцип: доказательность как функция

Большинство сервисов-«декодеров» состава ставят ингредиентам оценки вроде «хорошо», «плохо» или «опасно» и не объясняют, откуда они взялись. Ингредиум строится по обратному правилу:

- **У каждого утверждения есть источник.** Это нормативный акт, заключение научного комитета (SCCS/SCCNFP, CIR) или рецензируемое исследование с указанием дизайна и размера выборки.
- **Если проверенных данных нет, так и написано: «не проверено».** Пустое поле лучше догадки, поэтому числа не подставляются «по аналогии».
- **Видна сила доказательства.** Регламент, РКИ, модель на коже свиньи и «вторичный обзор» помечаются по-разному.

Это главное, чем приложение отличается от аналогов: и по содержанию, и по функциям. Косметолог может показать клиенту не мнение, а ссылку.

### Важно про Россию (ЕАЭС)

В России действует ТР ТС 009/2011 «О безопасности парфюмерно-косметической продукции». 28.10.2026 вступили в силу его изменения, утверждённые Решением Совета ЕЭК № 74 от 12.09.2025: расширены перечни запрещённых и ограниченных веществ, красителей, консервантов и УФ-фильтров ([IFCG](https://www.ifcg.ru/news/2026-03-05/ustanovlen-poradok-vvedenia-v-dejstvie-izmenenij-v-tr-ts-0092011/)). Позиции по конкретным веществам в базе пока **не сверены** с новой редакцией приложений, поэтому в карточках RU стоит «не проверено» со ссылкой на текст регламента. Сверка приложений ТР ТС с CosIng — первый пункт дорожной карты.

## 3. Два режима

**Потребитель** видит:
- что делает ингредиент, простыми словами;
- кому подходит и чего опасаться;
- есть ли ограничения в выбранной стране.

Без формул и таблиц концентраций.

**Косметолог** видит всё то же плюс:
- таблицу «концентрация → эффект → дизайн исследования»;
- правила ввода (pH, фаза, стабильность);
- синергию и конфликты с обоснованием;
- полный текст ограничений Приложений ЕС: тип продукта, максимум, условия, обязательные предупреждения на этикетке;
- номера регламентов и заключения SCCS;
- CAS и EC.

Режим переключается в один тап и запоминается.

## 4. Обучение и геймификация

Цель: превратить справочник в тренажёр, который хочется открывать каждый день.

### 4.1 Механики, которые уже есть
1. **Ингредиент дня.** Каждый день новая карточка, одна и та же у всех пользователей (выбирается по дате). Это повод зайти и тема для обсуждения в профессиональном сообществе.
2. **Интервальное повторение.** Карточки «вопрос → ответ» с самооценкой «знаю / сомневаюсь / не знаю». Интервалы растут по упрощённому алгоритму SM-2, неуверенные карточки возвращаются раньше.
3. **Бесконечная регуляторная викторина.** Вопросы *генерируются* из официальных Приложений: «Какой максимум для X в ЕС?», «В каком Приложении находится Y?», «Разрешено ли Z?». Поэтому они бесконечны, всегда актуальны (обновляются вместе с базой) и проверяемы: у каждого вопроса есть ссылка на позицию Приложения. Насколько нам известно, это новая механика: тест, который нельзя «выучить наизусть» и который не устаревает.
4. **Курс.** Модули от основ INCI до регуляторики. Урок — короткая теория плюс проверочные вопросы. Следующий модуль открывается после прохождения предыдущего.
5. **XP, уровни и серии.** XP за урок и правильные ответы. Уровни: Стажёр → Ассистент → Технолог → Эксперт → Наставник. Серия дней подряд с «заморозкой» на один пропуск в неделю, чтобы мотивация не ломалась от одного пропущенного дня.

### 4.2 Что предлагаем добавить (дорожная карта)
- **«Детектив состава».** Пользователь видит реальный INCI-список без названия и угадывает тип средства, ключевой актив и примерную концентрацию по положению в списке с учётом правила 1%.
- **«Лаборатория формулы»: регуляторный симулятор.** Пользователь собирает формулу из ингредиентов с процентами, выбирает рынок (ЕС/США/…) и тип продукта. Приложение мгновенно проверяет пределы Приложений и конфликты pH из карточек. Механика обучает через последствия: «ваш тоник не пройдёт в ЕС, потому что…».
- **Карта pH.** Перетаскивание активов на шкалу pH к их рабочему диапазону.
- **Дуэли.** Два косметолога отвечают на одинаковые сгенерированные вопросы на время.
- **Сертификат модуля** с перечнем пройденных тем и источников, например для портфолио.

## 5. Сканер состава

1. Фото этикетки → распознавание текста **на устройстве** (Tesseract.js, языки eng + rus). Фото никуда не отправляется. На iPhone можно также скопировать текст из фото системной функцией «Текст на фото» и вставить его.
2. Разбор: деление по запятым, нормализация, поиск в 33 тыс. названий CosIng с нечётким совпадением для опечаток OCR.
3. Результат:
   - **распознанные ингредиенты** и доля совпадений;
   - **профиль функций** (эмоленты, увлажнители, ПАВ, консерванты…);
   - **регуляторные флаги** по выбранной юрисдикции (для ЕС по Приложениям);
   - **активы с карточками** и ссылки на них;
   - **оценка типа средства и текстуры.** Это прозрачные правила по функциям ингредиентов и их положению в списке, а не измерение. Приложение показывает, почему сделан такой вывод (например: «ПАВ-очиститель в первой пятёрке → вероятно, очищающее средство»), и прямо пишет, что это гипотеза;
   - **напоминание о правиле 1%.** Ингредиенты с концентрацией ниже 1% могут идти в любом порядке после остальных (Регламент (ЕС) 1223/2009, ст. 19(1)(g)). Поэтому по месту в списке нельзя точно судить о проценте.

## 6. Оформление

Модные тенденции 2025–2026: полупрозрачные «стеклянные» панели с размытием фона в духе iOS, бенто-сетка на главном экране, крупная типографика, мягкие скругления, тактильные микроанимации.

- Темы: **системная** (следует настройке iOS/Android), **светлая**, **тёмная**, пресеты (*Лаборатория*, *Пудра*, *Шалфей*, *Полночь*) и **своя тема**: акцентный цвет, фон, радиус скругления, интенсивность «стекла».
- Отключение прозрачности и анимаций для слабых устройств и по системной настройке «Уменьшить движение» / «Понизить прозрачность».

## 7. Архитектура

- **PWA без сборщика:** HTML + CSS + ES-модули. В приложении нет зависимостей npm и ничего не нужно собирать, поэтому оно быстро грузится и легко проверяется.
- **Офлайн и обновления по воздуху:** Service Worker кэширует оболочку и данные. При выходе новой версии на GitHub Pages приложение показывает «Доступно обновление» и применяет его по тапу. Данные кэшируются отдельно и обновляются сами при изменении версии.
- **iOS:** установка через Safari → «Поделиться» → «На экран Домой». Приложение открывается без интерфейса браузера и учитывает «чёлку» и Dynamic Island (safe-area).
- **App Store (следующий шаг):** обёртка Capacitor вокруг той же PWA. Нужны Mac с Xcode и аккаунт Apple Developer. Обновления данных и интерфейса по-прежнему приходят по воздуху.
- **Производительность:** виртуализированный список (в DOM только видимые строки из 33 тыс.), поиск с задержкой ввода по предварительно нормализованному индексу.
- **Данные:** воспроизводимая сборка `tools/build_cosing.py` из исходных выгрузок `data-src/`.

## 8. Дорожная карта

1. Сверка позиций ТР ТС 009/2011 (редакция от 28.10.2026) с CosIng: юрисдикция RU для всей базы.
2. Расширение глубоких карточек до 100+ активов (кислоты, ретиноиды, пептиды, УФ-фильтры, консерванты) по тому же стандарту источников.
3. Перевод функций CosIng с официальными определениями из глоссария функций.
4. Корея (MFDS), Китай (STSC + IECIC), Япония (Стандарты косметики MHLW): полные перечни.
5. «Лаборатория формулы», «Детектив состава», дуэли.
6. Нативная iOS-обёртка (Capacitor) и публикация в App Store.
